# 烟台专属地标：实景轮廓重建

版本标记：`yantai-reference-20260831`。

## 范围

仅替换微信小程序烟台的四处地标。不是全城市重建，也不是实景测绘模型。
此前把张裕酒文化博物馆画成尖塔酒庄、把蓬莱阁画成多层塔，属于对象/结构错误，不只是细节不够。

- 烟台山灯塔：灰石城堡基座、乳白多面塔身、外挑观景层、逐级缩进灯室。
- 蓬莱阁：两层主阁、朱红明廊、两重檐、歇山屋顶、青绿色彩绘构件。
- 张裕酒文化博物馆：灰砖双层立面、灰瓦四坡顶、中央缓坡与双侧台阶。不是张裕卡斯特酒庄。
- 烟台市博物馆：宽台阶、六根正面石柱、长水平檐口、后退玻璃门厅。不是自然博物馆。

侧背立面仍为移动端简化表达，不声称逐窗、逐砖或真实尺寸复原。四处建筑在沙盘上的距离和比例为可读性构图，不是烟台真实地图位置。

## 实现

- `miniprogram/lib/yantaiLandmarks.js` 中四个专属 builder，烟台不再使用通用灯塔/亭/酒庄/博物馆工厂。
- 在 `landmarks.js` 注册四个独立节点，保留各自名称、包围盒、优先级、夜间发光材质。
- 烟台禁用通用圆展示台及发光圈；建筑使用自己的台基。
- 蓬莱阁前移。三处小范围 `frontClearanceZones` 为默认东南视角让出正面视线；scene 将数量限制为最多4个、半径最多1.6。
- 背景楼群高度、密度参数不变。前景避让会改变少量楼位，也会改变确定性生成器后续的楼型分配。
- 重复窗框、栏杆、石柱采用 InstancedMesh。四处合计50个 Mesh/InstancedMesh，11,660个三角形（不含文字标签、阴影额外绘制或整城）。
- 新增材质贴图由 DataTexture 生成，不下载图片，不实时调用 AI，不新增外部模型资产。

## 已验证与未验证

已执行：

1. 使用仓库同版 Three.js r162，在浏览器 WebGL 中实际渲染四个单体的正面、前侧、侧后方、昼夜模式。
2. 运行原小程序 scene.js、城市楼群、光照代码，只替换本次草稿，查看默认视角、旋转、夜景。
3. 从烟台切到上海再返回，检查无通用模型回退。
4. 几何回归：城市别名、四处名称及专属版本、顶点及实例矩阵有效性、地面边界、建筑占地互不相交、网格/三角形预算、材质实例隔离。
5. 上海入口烟雾测试，确保本次专属覆盖只影响烟台。

浏览器测试用 HTMLCanvasElement 代替微信 canvas，文字标签用 DOM canvas 适配。它验证真实几何和场景代码，但**不等于微信开发者工具/手机真机验证**。未测微信真机 FPS、GPU 内存、设备兼容性或审核包体。
