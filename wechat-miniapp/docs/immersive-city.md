# 全屏看城

## 用户操作

- 城市场景初始化成功后，画面右下角显示「全屏看城」。
- 点击后隐藏下方天气/搜索/心情入口面板，同一块 WebGL canvas 扩展到页面可用高度。
- 左上角始终保留「× 退出全屏」，右上角保留昼夜切换；位置根据状态栏与微信胶囊下缘计算。
- 保留既有单指旋转、双指缩放/俯仰操作，不新增地点点击功能。
- 退出恢复进入前的镜头轨道参数，并显示原有面板；节点不销毁，预报横向滚动、搜索内容、画报编辑数据不清空。
- 不调用系统全屏 API，不隐藏微信胶囊；本次不新增强制横屏、声音或新的地标互动。

## 实现边界

- `city-stage` 控制 canvas 布局；面板使用 hidden 与隐藏 class，不用 wx:if 销毁。
- canvas 上方的操作使用 cover-view，避免原生层级盖住退出按钮。
- `queueSceneResize` 在 setData 后测量实际尺寸；序号丢弃旧回调、最多重试两次零尺寸、页面销毁后停止操作。
- `scene.resize(w,h,{immersive})` 保存 angle/polar/radius/target/userInteracted，按限制视野的宽高比补偿距离；遵守原缩放边界。同尺寸重复测量不累乘缩放。
- 全屏内改变视角后退出，会恢复进入前视角；如果等待中的天气响应换了城市，不恢复旧城市的镜头。
- 未就绪、WebGL 初始化失败、心情编辑器打开时，不允许进入。
- 普通模式原有竖屏布局不重构。本次只验证全屏模式的窗口尺寸适配，并未启用小程序横屏配置。

## 自动验证

在仓库根目录：

```sh
node wechat-miniapp/tests/immersive-city.test.mjs
```

覆盖准备状态、进入/退出、控件安全位置、连续点击和旧测量回调、窗口变化、零尺寸重试、状态保留、卸载后回调失效，以及真实 scene.js resize 方法的相机恢复、无累乘缩放、手势重置和缩放上下限。

## 浏览器检查

使用实际页面事件与 WXSS、仓库 Three.js 场景，微信组件通过浏览器桥接模拟：

- 390×844 测试容器：普通 canvas 约390×435，全屏390×844；绘图缓冲区同步改变。
- 输入「烟台测试」，将小时预报滚动至513px；进入再退出后，两者均保留。
- 320×568 小屏全屏与横向窗口尺寸变化检查，退出/昼夜控制可见。
- 没有创建第二个 renderer，没有因切换重新请求天气或云素材。

这不是微信开发者工具/手机真机截图。微信原生 cover-view 层级、系统安全区、双指手势、真机帧率仍需拉取后真机验收。
