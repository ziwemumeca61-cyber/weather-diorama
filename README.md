# weather-diorama · 微缩城市天气

用 3D 微缩城市模型可视化实时天气 —— 下雨会有雨滴打在屋顶，起雾会有雾气笼罩街道。

一个坐落在白色托盘上的程序化生成微缩城市（高低楼群、东方明珠风格地标塔、江流、桥、树木、来往的小车与船），镜头缓缓环绕，顶部叠加天气预报卡片，并把真实天气"下"到城市上：雨滴敲打屋顶、雾气笼罩街道、晴日暖阳、夜晚万家灯火、以及雪 / 雷电 / 阴天。

## 特性

- **程序化微缩城市**：基于固定种子确定性生成，`InstancedMesh` 保证性能；夜间楼窗自动点亮。
- **城市地标档案**：按当前城市自动切换地标组合，夜间地标泛光；在 `src/scene/cityProfiles.ts` 注册即可扩展更多城市。已内置：
  - **北京**：天坛祈年殿、天安门、中国尊、央视大楼（自研中式屋顶生成器：凹曲面旋转顶 + 带翘角庑殿顶、琉璃瓦釉面、斗拱彩画、华表、灯笼）
  - **上海**：东方明珠 + 陆家嘴三件套（上海中心 / 金茂 / 环球金融中心）
  - **广州**：广州塔「小蛮腰」双曲面扭转格构
  - **西安**：大雁塔 + 钟楼
  - **杭州**：雷峰塔 + 西湖
  - **重庆**：来福士（横向摩天楼）+ 宽阔长江水道
  - **天津**：天津之眼摩天轮（旋转，跨在海河上）
  - **深圳**：平安金融中心 + 京基100 + 地王大厦双桅杆
  - **武汉**：黄鹤楼（五层金瓦飞檐）+ 绿地中心 + 长江大桥
  - **成都**：抱竹大熊猫 + 天府双塔 + 锦江
  - **苏州**：东方之门 + 虎丘斜塔（真的是斜的）

  - **山东全 16 地级市**：
    - **济南**：趵突泉三股水 + 超然楼 + 大明湖
    - **青岛**：栈桥回澜阁（伸进海里）+ 五月的风雕塑

    - **烟台**：烟台山灯塔（灯室夜间常亮）+ 海湾航运
    - **潍坊**：渤海之眼无辐摩天轮 + 满天风筝与长龙风筝
    - **济宁**：太白楼（运河名楼）+ 运河码头货栈 + 水滨牌坊
    - **泰安**：整座泰山（噪声地形嶙峋岩体、植被—花岗岩渐变、蜿蜒十八盘、红门 / 中天门 / 南天门、缆车、五岳独尊摩崖、玉皇顶）
    - **威海**：幸福门（带圆孔的玻璃门框）+ 海滨栈道 + 海中小岛灯标

- **城市专属水景**：水体随城市档案切换——上海黄浦江、重庆宽江、杭州西湖（湖泊）、北京 / 西安窄护城河（无航运）；地面、楼群范围、小船、桥、行人与车流路径全部自动适配。
- **千城千面回退**：未注册城市（搜索「巴黎 / 洛阳 / New York」等）不再千篇一律——以城市名哈希成种子，自动生成**专属外观**：天际线布局、楼群配色色相、地标造型（玻璃摩天楼 / 双塔连桥 / Art-Deco 退台塔 / 穹顶市政厅四选一）、地标配色与朝向、以及水景形态（江 / 湖 / 无）全部由城市名确定性推导。同一座城市每次来长得一样，不同城市各具其貌，零外部资源。
- **GLB 模型地标**：地标既可用程序化几何，也可直接加载 `.glb` 真实模型（自托管 Draco 解码、自动播放动画、加载失败回退程序化）。
  - **CC-BY 示范**：搜索「東京 / Tokyo」加载 [Littlest Tokyo](https://artstation.com/glenatron)（CC-BY 4.0）微缩街景模型，屏幕角标注署名。
  - 放模型到 `public/models/` 并在 `src/scene/cityProfiles.ts` 加一条 `models` 配置即可扩展，详见 `public/models/README.md`。
- **实时天气**：接入 [Open-Meteo](https://open-meteo.com) 免费天气 API（无需 API key），支持城市搜索与浏览器定位。
  - **搜索自动补全**：输入即联想候选城市（带省份 / 国家），键盘上下键选择；记住最近搜索，聚焦即回看。
  - **可分享链接**：当前城市写入地址栏 `?city=…`，复制链接即可分享 / 复现同一座城市。
- **真实昼夜**：按城市**当地实时时刻**在黎明→白天→黄昏→夜晚间连续过渡（天空、太阳角度、万家灯火同步渐变），而非固定档位硬切。夜幕降临时星空与月亮随之淡入。
- **天气特效**：
  - ☔️ **雨** — 雨柱下落 + 命中屋顶/地面的溅落涟漪
  - 🌫️ **雾** — 全局雾 + 贴地雾体笼罩街道
  - ❄️ **雪** — 缓慢飘落、随风漂移的雪花
  - ⛅ / ☁️ **多云 / 阴** — 高空漂移云团
  - ⛈️ **雷阵雨** — 暴雨 + 乌云 + 随机雷电闪光
- **昼夜光照**：白天 / 黄昏 / 夜晚在色温、光强、天空色之间平滑过渡，夜晚点亮楼窗与地标。
- **演示模式**：右下角控制面板可手动切换任意天气与时段，方便预览每种特效，随时"恢复实时天气"。

## 技术栈

Vite + React + TypeScript · three.js · @react-three/fiber · @react-three/drei · zustand

## 开发

```bash
npm install
npm run dev      # 启动开发服务器 http://localhost:5173
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
npm run smoke    # 无头冒烟测试（构建产物能渲染出场景、无 JS 报错）
```

## 部署

纯静态站，`dist/` 可托管在任何静态平台。当前通过 **Vercel** 部署（支持私有仓库）：

- Vercel 导入本仓库即可，零配置——自动识别 Vite（构建 `npm run build`，产物 `dist/`），此后每次推送 `main` 自动发布，PR 自动生成预览环境。
- CI（`ci.yml`）在每个 PR 上跑 构建 + 无头渲染冒烟。

> 天气数据通过 Open-Meteo 直连获取，需要可访问外网的环境。默认加载"上海"，无网络时场景以晴天回退，手动天气切换始终可用。

## 项目结构

```
src/
  scene/       托盘底座、程序化城市、地标塔、点缀道具、昼夜光照
  weather/     天气特效（雨/雾/雪/云/雷电）与 WMO 天气码映射
  data/        Open-Meteo API 客户端与 zustand 状态
  ui/          天气预报卡片、控制面板、加载态
```
